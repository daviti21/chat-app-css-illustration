# Chat App CSS Illustration

A responsive chat application interface recreated with HTML and CSS as a Frontend Mentor challenge.

## Features

* Chat application interface
* Conversation bubbles
* User profile section
* Responsive layout
* CSS-based UI elements and illustrations

## Technologies

* HTML
* CSS

## Purpose

This project was built to practice advanced CSS layouts, positioning, styling, responsive design, and recreating detailed UI designs from a reference.
